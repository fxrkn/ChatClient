# ChatClient

![ChatClient Banner](banner.png)

> **Disclaimer:** This project is currently in the testing stage.

Is your BEST friend (!) not texting you? Meh, you've got bigger problems — but that's okay.

ChatClient aims to make conversations with AI models feel more human, natural, and detailed, while providing a large context window even when using less capable models.
